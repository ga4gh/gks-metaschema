# Overview

GA4GH (the Global Alliance for Genomics and Health) develops the Genomic
Knowledge Standards (GKS). The GKS Metaschema Processor (MSP) processes
hand-edited JSON Schema source documents written in YAML (YAML Ain't Markup
Language). It resolves inheritance and imports to generate complete JSON Schema
and reStructuredText (RST) artifacts. MSP is used by GKS-Core, VRS, Cat-VRS,
and VA-Spec.

* [How It Works](schema-authoring/index.md): source YAML structure,
  product-level configuration, generated artifacts, and the standard build
  workflow.
* [Release Management](release-management/index.md): tools and processes that
  keep product versions and immediate upstream dependencies aligned for a
  release.
* [Example Workflow](example-workflow/index.md): develops and releases a
  foundation product and a dependent product together.
* [Development](development/index.md): MSP's internal processing model and
  contributor workflow.
